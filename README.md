# .github

Default **community health files** for [@finallyjay](https://github.com/finallyjay)'s
repositories.

GitHub automatically applies the files in this repository to any repository on the
account that does **not** provide its own copy. That lets every project share a
consistent baseline without duplicating boilerplate.

## What's here

| File | Applies as the default… |
| --- | --- |
| [`SECURITY.md`](./SECURITY.md) | Security / vulnerability disclosure policy |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Code of conduct (Contributor Covenant 2.1) |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Contribution guidelines |
| [`.github/ISSUE_TEMPLATE/`](./.github/ISSUE_TEMPLATE) | Bug report & feature request issue forms |
| [`.github/pull_request_template.md`](./.github/pull_request_template.md) | Pull request template |

A repository that ships its own version of any of these takes precedence over the
default here.
